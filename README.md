# Antigravity File Explorer

Antigravityがアクセス可能なローカルディレクトリのファイルを可視化し、ブラウザ上で簡単に確認・更新できるツールです。

## 🌟 主な機能

- **階層構造の表示**: フォルダとファイルをツリー形式で美しく表示します。
- **リアルタイム更新**: 「リストを更新」ボタンをクリックすることで、最新のファイル状態を再スキャンして反映します。
- **モダンなUI**: グラスモフィズムを採用した、ダークモードベースの洗練されたデザイン。
- **ファイルリンク**: 一覧のアイテムをクリックすることで、ブラウザがサポートしているファイル（画像など）を直接表示できます。

## 📂 構成ファイル

- `viewer/index.html`: メインのUI画面。
- `viewer/server.js`: API（更新処理）と静的ファイル提供を行うNode.jsサーバー。
- `viewer/update_files.js`: ローカルフォルダをスキャンし、`file_data.json`を作成するロジック。
- `viewer/file_data.json`: スキャンされたファイルリストのデータ（自動生成）。

## 🚀 起動手順

本ツールを使用するには Node.js がインストールされている必要があります。

1.  **サーバーの起動**
    ターミナルで以下のコマンドを実行してください。
    ```powershell
    node viewer/server.js
    ```

2.  **ブラウザでアクセス**
    ブラウザを開き、以下のURLにアクセスしてください。
    [http://localhost:8000/viewer/index.html](http://localhost:8000/viewer/index.html)

3.  **リストの更新**
    ファイルを追加・削除した後は、画面上の「リストを更新」ボタンを押すと最新の状態に同期されます。
